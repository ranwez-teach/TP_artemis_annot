# Donnees du TP

Placez ici les fichiers ouverts par Artemis pendant le TP.

Par defaut, le Codespace lance `data/example.embl`. Pour ouvrir un autre fichier au
demarrage, modifiez la commande dans `start-artemis.sh` ou passez le chemin voulu au
script :

```bash
bash start-artemis.sh data/votre-fichier.embl
```
